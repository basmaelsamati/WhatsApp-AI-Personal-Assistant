# WhatsApp AI Personal Assistant 🤖

An AI-powered WhatsApp personal assistant built with **n8n**, **Google Gemini**, **SerpApi**, **Google Calendar**, and **Evolution API**.

The workflow can receive WhatsApp messages, understand different types of content, use AI to process the request, search the web for current information, manage Google Calendar events, and respond through WhatsApp.

## ✨ Features

* 💬 **Text Messages**

  * Understands and responds to WhatsApp text messages.
  * Matches the user's language and tone.

* 🎙️ **Voice Messages**

  * Retrieves WhatsApp audio.
  * Converts the audio to a file.
  * Transcribes the recording using Google Gemini.
  * Sends the transcription to the AI Agent.

* 🖼️ **Image Messages**

  * Retrieves WhatsApp images.
  * Converts the media to a file.
  * Uses Google Gemini to analyze the image.
  * Can extract visible text from images.

* 🧠 **AI Assistant**

  * Uses Google Gemini as the language model.
  * Maintains conversation context using memory.
  * Responds naturally in Arabic, Egyptian Arabic, or English.

* 🔎 **Current Information**

  * Uses SerpApi for web searches.
  * Searches the web before answering time-sensitive questions.
  * Supports current prices, exchange rates, weather, news, and other recent information.

* 📅 **Google Calendar**

  * Checks upcoming events.
  * Searches events for specific dates.
  * Creates calendar events.
  * Uses AI to determine the required date and time.

* 🔊 **Text-to-Speech**

  * Converts AI responses into audio.
  * Uses a Qwen TTS endpoint.
  * Sends the generated audio back through WhatsApp.

* 📱 **WhatsApp Integration**

  * Uses Evolution API to receive and send WhatsApp messages.
  * Supports text, voice, and image messages.

## 📋 Requirements

Before importing the workflow, you need:

1. A running n8n instance.
2. Evolution API configured with a WhatsApp instance.
3. Google Gemini API credentials.
4. SerpApi credentials.
5. Google Calendar OAuth2 credentials.
6. A publicly accessible n8n webhook URL if Evolution API is running outside the same network.

## ⚙️ Setup

### 1. Import the Workflow

Import the JSON workflow file into n8n.

The workflow contains placeholder values instead of real credentials.

Examples:

```text
YOUR_GOOGLE_GEMINI_CREDENTIAL_ID
YOUR_SERPAPI_CREDENTIAL_ID
YOUR_GOOGLE_CALENDAR_CREDENTIAL_ID
YOUR_EVOLUTION_API_CREDENTIAL_ID
YOUR_WEBHOOK_ID
YOUR_WHATSAPP_CHAT_ID
YOUR_INSTANCE_NAME
```

Replace the placeholders with your own configuration inside n8n.

### 2. Configure Credentials

Create the required credentials in n8n:

* Google Gemini
* SerpApi
* Google Calendar OAuth2
* Evolution API

**Do not put API keys, OAuth tokens, passwords, or other secrets directly inside the workflow JSON.**

### 3. Configure Evolution API

Connect your WhatsApp instance through Evolution API and configure the webhook to point to your n8n webhook.

The webhook should use the production webhook URL generated by n8n.

### 4. Configure the WhatsApp Chat ID

The workflow contains a filter that can be configured to process messages from a specific WhatsApp chat.

Replace:

```text
YOUR_WHATSAPP_CHAT_ID@s.whatsapp.net
```

with your own value inside n8n.

### 5. Configure Google Calendar

Connect your Google Calendar account using OAuth2.

The AI Agent can then use Google Calendar to:

* Search events
* Create events
* Manage scheduled events

## 🔐 Security

This repository is designed to contain **no real credentials or API secrets**.

Before publishing your own workflow:

* Never commit API keys.
* Never commit OAuth access or refresh tokens.
* Never commit passwords.
* Never commit Evolution API keys.
* Never commit personal WhatsApp IDs.
* Never commit private webhook URLs.
* Remove execution data and pinned webhook data before publishing.
* Use placeholders such as `YOUR_API_KEY` instead of real values.
